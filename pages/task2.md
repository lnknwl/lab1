# Задание 2

**Описание**

Программа работает с динамическим массивом целых чисел

Реализованы:

- создание динамического массива с помощью `new[]`
- заполнение массива с клавиатуры
- поиск первого отрицательного элемента
- создание нового массива из элементов до первого отрицательного
- освобождение старого массива с помощью `delete[]`
- передача указателя в функцию через `int*&`
- обнуление указателя с помощью `nullptr`
