# Задание 3

**Описание**

В программе реализована структура `SafeArray` для работы с динамическим массивом

Реализованы:

- создание динамического массива
- получение элемента массива через функцию `getElement`
- возврат элемента по ссылке
- проверка выхода за границы массива
- вывод массива через константную ссылку
- изменение размера массива
- вывод удаляемых элементов при уменьшении массива
- заполнение новых элементов нулями при увеличении массива
