# Задание 4

**Описание**

Программа работает с двумерным динамическим массивом оценок студентов

Реализованы:

- выделение памяти под двумерный массив
- заполнение матрицы с клавиатуры
- вывод матрицы
- использование параметров по умолчанию
- вывод матрицы с рамкой и без рамки
- вывод пользовательского заголовка
- освобождение памяти двумерного массива
